Obiettivo

Mostrare con esempi minimi in R che:

  • piccole scelte analitiche (gradi di libertà) possono cambiare la conclusione;
  • questo alimenta risultati “significativi” per caso;
  • confondere EDA e confermativa porta a fishing (p-hacking/HARKing);
  • la teoria serve a vincolare le scelte (la statistica non la sostituisce).

Definizione: gradi di libertà dello sperimentatore

Gradi di libertà dello sperimentatore
insieme delle scelte possibili (spesso non pre-specificate) su:
  • esclusioni (outlier, missing);
  • trasformazioni;
  • costruzione di variabili (compositi);
  • modello statistico;
  • regole di stopping (quando smettere di raccogliere dati).

Più gradi di libertà = più “bivi” nel garden of forking paths.

Perché è un problema per la replicabilità

Se le scelte sono guidate dall’esito (es. “cerco \(p\) < .05”):

  • aumenta la probabilità di falsi positivi;
  • la “storia” si adatta al campione;
  • in un nuovo campione l’effetto tende a sparire.

Questo è esattamente il tipo di problema che le Lezioni 14–16 hanno anticipato discutendo i limiti dell’inferenza frequentista e del valore-p.

EDA vs confermativa (promemoria)

  • EDA: esplorare, generare ipotesi;
  • Confermativa: testare ipotesi predefinite.

Problema tipico:

fare EDA, ma presentarla come confermativa.

Demo 1: outlier e conclusioni diverse

Idea:

  • due condizioni (A, B);
  • dati con alcuni outlier;
  • cambiamo la soglia di esclusione outlier;
  • osserviamo che la conclusione (valore-\(p\)) può cambiare.

Simuliamo due gruppi con outlier

Vogliamo ottenere tre conclusioni diverse a seconda della soglia:

  • dataset completo: nessuna differenza (p > .05);
  • esclusione outlier con |z| > 2: effetto (p < .05);
  • esclusione outlier con |z| > 3: nessun effetto (p > .05).

Per essere sicuri che questo accada sempre, usiamo una simulazione che cerca un dataset che soddisfi questi criteri.

simulate_case <- function(seed_start = 2026, max_tries = 5000,
                          n = 40, mu_A = 0, mu_B = 0.45,
                          extreme_A = 10, extreme_B = -10,
                          moderate_A = 6.3) {

  for (k in 0:max_tries) {
    set.seed(seed_start + k)

    A <- rnorm(n, mean = mu_A, sd = 1)
    B <- rnorm(n, mean = mu_B, sd = 1)

    # Outlier estremi (molto influenti, tipicamente |z| > 3)
    A[c(5, 12)] <- A[c(5, 12)] + extreme_A
    B[7]        <- B[7] + extreme_B

    # Outlier "moderato" (tipicamente 2 < |z| <= 3): rimosso da z=2 ma non da z=3
    A[20] <- A[20] + moderate_A

    dat1 <- data.frame(
      y = c(A, B),
      group = rep(c("A", "B"), each = n)
    )

    # p-value dataset completo
    p0 <- t.test(y ~ group, data = dat1, var.equal = TRUE)$p.value

    # z-score sul totale
    z <- scale(dat1$y)[,1]

    dat_z2 <- dat1[abs(z) <= 2, ]
    dat_z3 <- dat1[abs(z) <= 3, ]

    # p-value dopo esclusione outlier
    p2 <- t.test(y ~ group, data = dat_z2, var.equal = TRUE)$p.value
    p3 <- t.test(y ~ group, data = dat_z3, var.equal = TRUE)$p.value

    if (p0 > 0.05 && p2 < 0.05 && p3 > 0.05) {
      attr(dat1, "seed") <- seed_start + k
      return(dat1)
    }
  }

  stop("Nessun dataset trovato: prova ad aumentare max_tries o a cambiare moderate_A.")
}

Cosa abbiamo mostrato?

  • La domanda è la stessa: “A e B differiscono?”.
  • I dati sono gli stessi (tranne le esclusioni).
  • La conclusione può cambiare perché:
    • la soglia degli outlier è una decisione analitica,
    • spesso non è predefinita.

Se scegliamo il criterio di esclusione dopo aver visto i risultati, stiamo “ottimizzando” il valore-\(p\).

p-hacking e HARKing

p-hacking
modificare l’analisi (selezioni, trasformazioni, modelli) per ottenere \(p\) < .05.
HARKing
formulare (o riscrivere) ipotesi dopo aver visto i risultati, presentandole come a priori.

Demo 2: variabile composita e conclusioni opposte

Idea:

  • più indicatori di “benessere”,
  • costruiamo un composito (media di item/scale),
  • scegliamo sottoinsiemi diversi,
  • otteniamo conclusioni diverse (anche nel segno).

Costruiamo i dati in modo che:

  • con un composito “coerente” otteniamo p < .05
  • includendo anche indicatori problematici otteniamo p > .05
  • con un subset alternativo otteniamo effetto opposto (segno invertito)

Simuliamo indicatori di benessere

Scenario: 8 indicatori.

  • i1–i4 misurano benessere (coerenti tra loro),
  • i5–i8 misurano in realtà distress (costrutto diverso / direzione opposta),
    ma vengono trattati come se fossero indicatori di benessere (errore tipico senza una teoria chiara).

# Funzione per generare dati che soddisfano i criteri
simulate_wellbeing <- function(seed_start = 3964, max_tries = 5000, n = 80) {
  for (k in 0:max_tries) {
    set.seed(seed_start + k)
    
    group <- rep(c("A", "B"), each = n/2)
    
    # Tratti latenti con effetti opposti:
    # - benessere più alto in B
    # - distress più alto in A
    wellbeing <- rnorm(n, 0, 1) + ifelse(group == "B", 0.6, 0)
    distress  <- rnorm(n, 0, 1) + ifelse(group == "A", 0.6, 0)
    
    # Funzione per generare item con un dato loading e rumore
    make_item <- function(lat, loading, noise_sd = 0.7) {
      loading * lat + rnorm(length(lat), 0, noise_sd)
    }
    
    # Indicatori di benessere (caricano su wellbeing)
    i1 <- make_item(wellbeing, loading = 0.9, noise_sd = 0.6)
    i2 <- make_item(wellbeing, loading = 0.9, noise_sd = 0.6)
    i3 <- make_item(wellbeing, loading = 0.5, noise_sd = 0.8)  # più debole
    i4 <- make_item(wellbeing, loading = 0.5, noise_sd = 0.8)
    
    # Indicatori di distress (caricano su distress)
    i5 <- make_item(distress,  loading = 0.9, noise_sd = 0.6)
    i6 <- make_item(distress,  loading = 0.9, noise_sd = 0.6)
    i7 <- make_item(distress,  loading = 0.5, noise_sd = 0.8)
    i8 <- make_item(distress,  loading = 0.5, noise_sd = 0.8)
    
    dat <- data.frame(group, i1, i2, i3, i4, i5, i6, i7, i8)
    
    # Compositi
    dat$comp_wb   <- rowMeans(dat[, c("i1","i2","i3","i4")])
    dat$comp_all  <- rowMeans(dat[, paste0("i", 1:8)])
    dat$comp_alt  <- rowMeans(dat[, c("i1","i2","i5","i6")])
    
    # Test t per ciascun composito (varianze uguali)
    p_wb  <- t.test(comp_wb ~ group, data = dat, var.equal = TRUE)$p.value
    p_all <- t.test(comp_all ~ group, data = dat, var.equal = TRUE)$p.value
    p_alt <- t.test(comp_alt ~ group, data = dat, var.equal = TRUE)$p.value
    
    # Medie per gruppo per il composito alternativo
    m_alt <- t.test(comp_alt ~ group, data = dat, var.equal = TRUE)$estimate
    
    # Condizioni desiderate:
    # - p_wb < 0.05  (effetto benessere significativo)
    # - p_all > 0.05 (effetto totale nullo)
    # - p_alt < 0.05 e media gruppo A > media gruppo B (inversione)
    if (p_wb < 0.05 && p_all > 0.05 && p_alt < 0.05 && m_alt[1] > m_alt[2]) {
      attr(dat, "seed") <- seed_start + k
      return(dat)
    }
  }
  stop("Nessun dataset trovato: prova a modificare le grandezze degli effetti o i loading.")
}

Cosa abbiamo mostrato?

  • La “variabile dipendente” non è un dato naturale: è una costruzione.
  • Includere/escludere indicatori è una decisione analitica.
  • Senza una teoria chiara:
    • si può scegliere il subset che “funziona”,
    • e costruire una narrazione a posteriori.

Il punto epistemico: la teoria vincola i gradi di libertà

Senza teoria:

  • i costrutti sono ambigui,
  • gli indicatori sono “sostituibili”,
  • l’analisi diventa ricerca del risultato.

Con la teoria:

  • si definisce il costrutto,
  • si giustifica la scelta degli indicatori,
  • si pre-specificano le analisi (analisi confermativa).

Fishing nei dati: perché sembra funzionare

Se provi molte analisi:

  • qualcuna darà \(p\) < .05 per caso,
  • soprattutto con effetti piccoli e misure rumorose.

La statistica non può sostituire la teoria:
può solo quantificare l’incertezza dato un modello e scelte definite.

Una nota bayesiana

Il framework bayesiano non è immune da questi problemi, ma li gestisce diversamente. La scelta esplicita dei prior (Lezione 17) e l’interpretazione diretta della posterior (Lezione 20) rendono le assunzioni più visibili.

Tuttavia, anche un’analisi bayesiana può essere “ottimizzata” se si provano molti modelli e si presenta solo quello che conferma la propria ipotesi.

La trasparenza del workflow resta essenziale.

Ricordiamo

Dati con effetti piccoli e misure rumorose sono la condizione tipica della ricerca psicologica.

Ma soprattutto,

  • sono quelli in cui le assunzioni e le decisioni analitiche hanno l’impatto maggiore;
  • sono quelli in cui l’inferenza frequentista può produrre conclusioni instabili se usata in modo automatico;
  • sono quelli in cui l’approccio bayesiano è particolarmente utile, perché rende esplicite le assunzioni e integra l’incertezza in modo coerente.

Come interviene l’Open Science

Buone pratiche (collegate ai problemi visti):

  • pre-registrazione: specificare a priori ipotesi e analisi;
  • condivisione di codice: verificabilità delle scelte;
  • report riproducibile: riduce errori e “aggiustamenti” invisibili;
  • multiverse analysis (idea): mostrare l’effetto di molte scelte plausibili.

Ma la causa di fondo può essere teorica:

teorie deboli → molte scelte arbitrarie → fishing.

Dalla scienza “spazzatura” alla scienza solida

Comprendere e prevenire i vizi della ricerca: Data Fishing, Junk Science e Zombie Ideas

Obiettivo: identificare le pratiche di ricerca che generano risultati sorprendenti ma inaffidabili e individuare gli strumenti per una scienza più solida e replicabile.

Perché questo punto è cruciale?

La ricerca è particolarmente vulnerabile a conclusioni ingannevoli quando si combinano tre condizioni:

  • effetti piccoli o inesistenti,
  • misure rumorose o indirette,
  • ipotesi vaghe ed elastiche.

In questo contesto, la pratica del “data fishing” produce facilmente risultati sorprendenti (“effetto wow”) ma estremamente fragili.

  • La conseguenza sistematica è la proliferazione di ciò che Andrew Gelman e altri chiamano “Junk Science” (scienza spazzatura).

Cos’è il Data Fishing?

Data Fishing (o P-Hacking): esplorare sistematicamente diverse scelte analitiche, modelli, subset di dati o variabili di outcome, fino a quando non emerge un risultato “interessante” (es. p < 0.05), per poi costruire una narrazione a posteriori che lo giustifichi.

È tipicamente associato a:

  • molti gradi di libertà analitici (scelte non vincolate a priori);
  • selezione selettiva dell’outcome, delle covariate o del campione;
  • reporting parziale, mostrando solo le analisi “riuscite”.

Cos’è la Junk Science?

Junk Science (definizione operativa): risultati scientifici falsi o estremamente fragili che ottengono visibilità e credibilità perché soddisfano criteri “narrativi” piuttosto che scientifici.

Caratteristiche distintive:

  1. sembrano controintuitivi o creano un forte “effetto wow”;
  2. sono supportati da evidenza statisticamente debole (p-hacked);
  3. non reggono a repliche indipendenti e rigorose;
  4. vengono mantenuti in vita da incentivi accademici, media e storytelling persuasivo.

(Non replicabile, ma citabile) – A. Gelman

Come nasce una “Zombie Idea”?

  1. Teoria debole (ipotesi vaghe, costrutti mal definiti).
  2. Molti gradi di libertà analitici (si provano molte analisi).
  3. Ricerca della significatività (consapevole o meno; p-hacking).
  4. Pubblicazione selettiva (bias verso la novità e risultati “positivi”).
  5. Storia a posteriori (HARKing: ipotesi formulate dopo i risultati).
  6. Bassa replicabilità (l’effetto sparisce in studi successivi).
  7. “Zombie idea” (l’idea sopravvive nonostante le prove contrarie).

Cosa sono le “Zombie ideas”?

Zombie idea: un’idea o un’affermazione che è stata empiricamente confutata (o non è mai stata solidamente supportata), ma che continua a “essere citata” nella cultura scientifica, divulgativa e popolare.

Perché sopravvivono?

  • Utilità narrativa: sono semplici, memorabili e forniscono “una buona storia”.
  • Incentivi istituzionali: supportano un’ideologia, un prodotto o una carriera.
  • Inerzia cognitiva e mediatica: sono radicate nei libri di testo e nel senso comune.

Zombie Ideas #1: Priming comportamentale

L’idea: esporre le persone a parole legate alla vecchiaia (es. “Florida”, “Bingo”) le fa camminare più lentamente all’uscita del laboratorio (Bargh, Chen, & Burrows, 1996).

  • Origine: studio iconico sul priming sociale, pubblicato sul Journal of Personality and Social Psychology.
  • Stato delle repliche: fallimenti di replica su larga scala, con campioni di migliaia di partecipanti (Doyen et al., 2012; Harris, Coburn, Rohrer, & Pashler, 2013). Una meta-analisi ha mostrato un effetto prossimo allo zero.
  • Perché è una zombie idea? Continua ad apparire nei libri di testo di psicologia sociale ed è usata come esempio principe del “potere dell’inconscio” nella divulgazione, nonostante le prove contrarie.

Zombie Ideas #2: Stili di apprendimento

L’idea: le persone apprendono meglio se l’insegnamento è adattato al loro stile di apprendimento preferito (Visivo, Auditivo, Cinestesico).

  • Origine: modello popolare negli anni ’70-’80, ampiamente adottato nel mondo dell’istruzione e della formazione aziendale.
  • Stato delle repliche: rivisitazioni sistematiche della letteratura (Pashler et al., 2008) non trovano alcuna evidenza che l’istruzione “abbinate” allo stile migliori l’apprendimento. L’effetto è un classico caso di matching fallacy.
  • Perché è una zombie idea? È ancora una delle teorie più insegnate nei corsi di formazione per insegnanti e viene usata da innumerevoli siti educativi e aziende di consulenza. La sua semplicità e intuitività la rendono resistente alla smentita.

Zombie Ideas #3: Intelligenza emotiva (come predittore di successo)

L’idea: l’intelligenza emotiva (QE) è un predittore del successo lavorativo e di vita più importante del QI.

  • Origine: resa popolare da Daniel Goleman (1995) sulla base di risultati iniziali promettenti, ma spesso basati su misure self-report e campioni limitati.
  • Stato delle repliche: le meta-analisi mostrano che, quando misurata come abilità (e non come tratto di personalità), la correlazione dell’IE con la performance lavorativa è modesta e non supera quella delle variabili di personalità di base (Joseph & Newman, 2010). L’affermazione “più importante del QI” è priva di supporto empirico.
  • Perché è una zombie idea? È diventata un pilastro della consulenza HR e della letteratura manageriale. L’idea che il “cuore” conti più della “mente” ha un fascino narrativo irresistibile.

Zombie Ideas #4: Effetto Mozart

L’idea: ascoltare Mozart rende più intelligenti, specialmente nei bambini (effetto sui compiti spaziali).

  • Origine: studio di Rauscher et al. (1993) su studenti universitari, che mostrava un miglioramento temporaneo in un compito di ragionamento spaziale.
  • Stato delle repliche: l’effetto originale era di breve durata (10-15 minuti) e specifico per un tipo di compito. Le repliche hanno mostrato che qualsiasi stimolo piacevole o eccitante (es. una storia di Stephen King) produce lo stesso risultato e che l’effetto è nullo nei bambini. La casa editrice dello stato della Georgia ha smesso di distribuire CD di Mozart ai neonati dopo le critiche.
  • Perché è una zombie idea? È diventata un fenomeno culturale e commerciale (CD per bambini, corsi di musica). L’idea che la musica classica “potenzi il cervello” è troppo bella e semplice per morire.

Perché questi esempi sono istruttivi?

Questi esempi condividono tutti le caratteristiche della junk science e delle zombie ideas:

  1. Effetto Wow: sembrano spiegare fenomeni complessi (successo, apprendimento, intelligenza) in modo semplice e controintuitivo.
  2. Teoria Debole: i costrutti (“priming sociale”, “stile di apprendimento”, “intelligenza emotiva”) sono spesso mal definiti e misurati in modo inaffidabile.
  1. Incentivi: alimentano un’industria di libri, consulenze, test e prodotti formativi.
  2. Inerzia: sono così radicati nel senso comune e nei testi introduttivi che continuano a essere citati anche dopo essere stati smentiti.

Conclusione: le zombie ideas ci ricordano che la scienza non è solo un metodo, ma anche un’istituzione sociale. Senza un costante lavoro di auto-correzione e di educazione critica, le idee sbagliate continuano ad accompagnarci.

Un fenomeno trasversale

La junk science può fiorire in qualsiasi disciplina dove si combinano:

  • effetti di piccola entità;
  • dataset complessi con molte variabili;
  • misure rumorose o surrogate;
  • forti incentivi alla pubblicazione di risultati “sensazionali”.

Discipline a rischio:

  • Psicologia sociale.
  • Medicina (soprattutto nutrizione/epidemiologia).
  • Neuroscienze (con neuro-imaging).
  • Economia.
  • Scienze politiche.

Esempi concreti di Zombie Ideas

1. Vaccini e autismo

  • Origine: studio fraudolento di Wakefield (The Lancet, 1998).
  • Stato: ritirato nel 2010. Ampiamente confutato da decine di studi successivi.
  • Perché è uno zombie? Continua a influenzare le scelte vaccinali per paura, supportato da movimenti no-vax e aneddoti mediatici.

Esempi concreti di Zombie Ideas

2. MBTI e performance lavorativa

  • Origine: indicatore di personalità Myers-Briggs (basato su teorie non validate).
  • Problemi: tipologie dicotomiche, bassa affidabilità test-retest, validità predittiva per la performance lavorativa quasi nulla.
  • Perché è uno zombie? Enormemente popolare nelle HR per la sua semplicità, nonostante l’evidenza scientifica contraria.

Dall’effetto “Wow” alla replica fallita

Lo studio originale (Damisch et al., 2010):

  • Ipotesi: un oggetto “fortunato” migliora la performance.
  • Risultato: chi usa la “pallina fortunata” ottiene più putt (d = 0.81, un effetto grande).
  • Caratteristica: 6 esperimenti, tutti con valori-p inferiori a .05.

Le repliche (Calin-Jageman & Caldwell, 2014; Dickhäuser et al., 2020):

  • Metodo: due studi pre-registrati, ad alta potenza, svolti in collaborazione con gli autori originali.
  • Risultato: effetto vicino allo zero. L’analisi (p-curve) dei dati originali suggerisce un probabile p-hacking.

Conclusione: un classico caso di risultato “appetibile mediaticamente” ma non replicabile.

Valutare la robustezza di uno studio

Per capire se un risultato è solido o solo rumore, chiediti:

  • teoria: l’ipotesi era precisa e falsificabile, o elastica e vaga?
  • outcome: era unico e pre-specificato, o ne sono stati provati molti?
  • campione: la potenza statistica era sufficiente per rilevare un effetto piccolo?
  • Misura: l’outcome era affidabile e valido?
  • Analisi: era pre-registrata o è stata adattata ai dati?
  • Reporting: gli autori forniscono gli script delle analisi statistiche svolte?
  • Repliche: esistono repliche indipendenti e pre-registrate?

Tre antidoti

  1. Teoria solida e previsioni rischiose
    • Costrutti ben definiti.
    • Predizioni precise e falsificabili (non un generico “qualcosa cambierà”).
  1. Disegno confermativo (non solo esplorativo)
    • Pre-registrazione: definire ipotesi, piano analitico e outcome primario prima di vedere i dati.
    • Separare chiaramente le analisi esplorative da quelle confermative.
  1. Open Science
    • Condivisione di dati, codice e materiali.
    • Incentivare le repliche.
    • Registered reports (la peer review avviene prima della raccolta dati).

Teoria e metodo: un binomio inseparabile

Senza una teoria solida:

  • ogni pattern nei dati può essere “spiegato” a posteriori;
  • si seleziona rumore statistico e si costruisce una storia plausibile;
  • la replicazione diventa impossibile o inutile.

Con una teoria solida e metodi rigorosi:

  • si riducono drasticamente i gradi di libertà del ricercatore;
  • la distinzione tra esplorazione e conferma è chiara;
  • un fallimento nella replica è un’informazione preziosa sul fenomeno o sulla teoria.

“La statistica quantifica l’incertezza dato un modello. La teoria ci dice quale modello ha senso testare.”

Take-Home Message

  • I risultati “wow” e controintuitivi in contesti rumorosi sono quasi sicuramente falsi.
  • La junk science nasce da una catena di pratiche discutibili, dal data fishing al reporting selettivo.
  • Le zombie ideas sopravvivono per inerzia narrativa e istituzionale, non per supporto empirico.
  • L’antidoto è una scienza pre-registrata, aperta e incentrata sulla teoria, che privilegi la credibilità a lungo termine alla sorpresa a breve termine.

Perché la crisi della replicabilità ha tardato a emergere?

Un fatto storico sorprendente:

  • critiche molto simili a quelle attuali
  • erano già presenti decenni fa
  • ma non hanno prodotto riforme sistemiche.

Domanda chiave:

Perché la crisi è esplosa solo dopo il 2010 (Gelman & Vazire, 2021)?

Il ruolo del contesto storico

  • Intorno al 2010
  • cambia il modo di pensare nelle scienze comportamentali
  • non per nuove idee in sé
  • ma perché il campo era pronto al cambiamento.

Le idee contano, ma soprattutto conta il contesto.

Le critiche c’erano già (molto prima)

Già tra anni ’60–’90

  • Campbell, Cronbach, Meehl e Petrinovich (1990)

criticavano:

  • mismatch tra statistica e teoria,
  • uso rituale dei test,
  • debolezza dei costrutti,
  • inferenze eccessive da dati rumorosi.

Ma rappresentavano una minoranza.

Domanda cruciale (Gelman & Vazire, 2021)

Se le argomentazioni erano solide:

  • perché sono state ignorate?
  • cosa ha impedito la riforma?
  • perché il sistema ha continuato a funzionare “come se nulla fosse”?

Prima risposta: il successo rafforza lo status quo

Nei campi accademici:

  • pubblicazioni,
  • premi,
  • visibilità mediatica,
  • libri di successo,

sono segnali di successo, non di verità.

Se il sistema “premia”:

  • risultati nuovi,
  • storie interessanti,
  • conclusioni forti,

allora non c’è incentivo al cambiamento.

Seconda risposta: le critiche erano “negative”

Molte critiche dicevano:

  • “servono teorie più forti”,
  • “servono misure migliori”,
  • “servono inferenze più caute”.

Problema:

  • sono diagnosi corrette,
  • ma non indicano una procedura operativa chiara.

È difficile riformare un sistema dicendo solo: “non fate così”.

Terza risposta: la psicologia stava funzionando

Tra 1970 e 2000:

  • grandi progressi in:

    • psicologia dello sviluppo, CBT, giudizio e decisione;

  • forte influenza su:

    • economia comportamentale, neuroscienze.

Conclusione scomoda:

i metodi statistici erano subottimali, ma non impedivano il progresso.

Quarta risposta: nessuna pressione esterna

In altri campi:

  • le crisi arrivano spesso da campi vicini.

Esempio:

  • la statistica cambia con il machine learning.

In psicologia, per molto tempo:

  • non c’era una forza esterna che rendesse costoso continuare come prima.

Il sistema poteva permettersi di ignorare le critiche, perché funzionava abbastanza bene da non dover essere modificato.

Allora perché tutto cambia dopo il 2010?

Gelman & Vazire (2021) propongono una combinazione di fattori.

Non una causa, ma una congiuntura.

Fattore 1: social media e connessione tra critici

Prima:

  • ricercatori scettici isolati,
  • 1–2 persone per dipartimento.

Dopo:

  • blog,
  • Twitter/X,
  • forum,
  • scambio rapido di idee.

Effetto chiave:

rendere visibile un dissenso che già esisteva.

Fattore 2: tecnologia e Open Science

Cambiamenti pratici:

  • condivisione di dati e codice,
  • preregistrazioni,
  • repository,
  • software open source.

Ora diventa legittimo chiedere:

  • “fammi vedere i dati”,
  • “fammi vedere le analisi”.

La trasparenza diventa tecnicamente possibile.

Fattore 3: dati più economici, repliche possibili

  • Survey online.
  • Campioni di convenienza.
  • Costi più bassi.

Conseguenza:

  • repliche ad alta potenza diventano fattibili,
  • i risultati fragili vengono smascherati.

Senza questi strumenti:

la crisi non avrebbe potuto emergere.

Fattore 4: crisi di generalizzabilità

Aumenta la consapevolezza epistemologica che:

  • campioni WEIRD (Western, Educated, Industrialized, Rich, Democratic),
  • operazionalizzazioni ristrette dei costrutti,
  • setting sperimentali decontestualizzati,

compromettono sistematicamente:

  • la validità esterna (generalizzabilità cross-culturale e ecologica),
  • l’ampiezza teorica (breadth dei costrutti psicologici),
  • la validità di costrutto (ecological validity delle misurazioni).

Questo genera un paradigma di auto-critica metodologica che trascende la sola replicabilità, interrogandosi sulla portata nomologica delle teorie psicologiche.

Fattore 5: insider–outsider

Ruolo chiave di ricercatori che:

  • possiedono competenza e credibilità sufficienti per essere ascoltati;
  • operano ai margini del campo o in aree adiacenti;
  • non dipendono completamente dagli incentivi dominanti del sistema.

Questa posizione consente di:

  • riconoscere problemi strutturali,
  • nominarli esplicitamente,
  • proporre alternative senza eccessivi costi reputazionali.

Abbastanza dentro per capire, abbastanza fuori per criticare.

Fattore 6: pressione mediatica e “wow science”

A partire dagli anni 2000:

  • forte popolarizzazione della psicologia (divulgazione, best seller, TED talks, media generalisti);

  • crescente domanda di spiegazioni:

    • semplici,
    • immediate,
    • applicabili alla vita quotidiana.

Questa domanda ha prodotto un effetto sistemico:

  • premia risultati “forti” e controintuitivi,
  • riduce la tolleranza per incertezza e risultati nulli,
  • aumenta l’accettazione di evidenza debole ma narrativamente efficace.

Un contesto ideale per la proliferazione della junk science.

Forse una crisi era inevitabile

Ipotesi di Gelman & Vazire (2021):

  • le criticità metodologiche erano presenti da tempo;

  • il sistema ha continuato a funzionare nonostante tali limiti;

  • col tempo si è accumulata una discrepanza crescente tra:

    • ambizioni teoriche,
    • forza dell’evidenza empirica.

Intorno al 2010 questa discrepanza è diventata visibile e condivisa.

Non è che prima mancassero le critiche, è che solo allora il sistema non poteva più assorbirle senza cambiare.

Collegamento con la lezione

Quello che abbiamo visto oggi:

  • data fishing
  • gradi di libertà
  • junk science
  • zombie ideas
  • Open Science

non sono “mode” recenti, ma risposte tardive a problemi strutturali.

Messaggio finale

  • La statistica non può compensare una teoria debole.
  • La trasparenza non può sostituire una domanda di ricerca ben posta.
  • Le pratiche di Open Science non generano teoria.

Ma:

senza una teoria che vincoli le ipotesi, l’analisi seleziona rumore e la ricerca scientifica scivola verso la junk science.
