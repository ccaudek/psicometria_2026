Dalla regressione al caso più semplice

Nella Lezione 24 abbiamo introdotto il modello di regressione lineare bayesiano: sonno ~ stress_c. Oggi ci concentriamo sul caso più semplice possibile: il modello a sola intercetta y ~ 1.

Questo modello stima un unico parametro — la media della popolazione — e ci permette di vedere in azione tutti gli strumenti bayesiani che abbiamo costruito finora: prior, posterior, probabilità dirette, confronto cn il frequentismo.

Obiettivi

  1. Comprendere il problema dell’inferenza su una media.
  2. Calcolare e interpretare il test t per un campione.
  3. Vedere come un outlier può distorcere i risultati.
  4. Introdurre l’approccio bayesiano robusto.
  5. Confrontare le due filosofie inferenziali.

Parte 1: il problema

Una domanda semplice

Un ricercatore misura il livello di ansia di stato in un campione di studenti universitari durante la sessione d’esami.

Domanda: Il livello medio di ansia in questa popolazione è diverso dal valore normativo (\(\mu_0\) = 40)?

Questa è forse la domanda più comune in psicologia: confrontare una media con un valore di riferimento.

I dati

Parte 2: l’approccio frequentista

Il test \(t\) per un campione

L’approccio classico — quello discusso nelle Lezioni 14–16 — usa il test \(t\):

\[ t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}}, \] dove:

  • \(\bar{x}\) è la media campionaria,
  • \(\mu_0\) è il valore di riferimento (40),
  • \(s\) è la deviazione standard campionaria,
  • \(n\) è la numerosità.

Calcolo “a mano”

mu_0 <- 40  # Valore normativo

# Errore standard
se <- deviazione / sqrt(n)

# Statistica t
t_obs <- (media - mu_0) / se

cat("Errore standard:", round(se, 3), "\n")
Errore standard: 0.768 
cat("t osservato:", round(t_obs, 3), "\n")
t osservato: 6.119

Il valore-\(p\)

# Gradi di libertà
gdl <- n - 1

# p-value (test a due code)
p_value <- 2 * (1 - pt(abs(t_obs), gdl))

cat("Gradi di libertà:", gdl, "\n")
Gradi di libertà: 19 
cat("p-value:", round(p_value, 4), "\n")
p-value: 0

Con p < 0.05, l’approccio frequentista conclude: “rifiutiamo \(H_0\)”.

Verifica con R

risultato_t <- t.test(ansia, mu = 40)
risultato_t

    One Sample t-test

data:  ansia
t = 6.1189, df = 19, p-value = 6.983e-06
alternative hypothesis: true mean is not equal to 40
95 percent confidence interval:
 43.09232 46.30768
sample estimates:
mean of x 
     44.7

Cosa significa questo risultato?

L’interpretazione frequentista:

“Se la vera media fosse 40, la probabilità di osservare una differenza così estrema (o più estrema) è inferiore a 0.00000698.”

Ma attenzione: come abbiamo visto nella Lezione 15, questo NON dice:

  • quanto è probabile che μ = 40;
  • quanto è probabile che μ ≠ 40;
  • qual è il valore più plausibile di μ.

Parte 3: quando il test \(t\) inganna

Un nuovo scenario

Immaginiamo di misurare il tempo di reazione (in ms) in un compito cognitivo.

# Dati con un outlier
tempi <- c(320, 315, 310, 318, 312, 318, 321, 310, 315, 322,
           318, 312, 317, 319, 313, 324, 316, 329, 321, 890)

cat("Media:", round(mean(tempi), 1), "ms\n")
Media: 346 ms
cat("Mediana:", median(tempi), "ms\n")
Mediana: 318 ms

Notiamo qualcosa di strano?

Visualizziamo i dati

L’approccio “ingenuo”

Poniamoci il problema di stabilire se la media della popolazione abbia un valore minore di 320.

Un ricercatore “pigro” usa R senza guardare i dati:

test_con_outlier <- t.test(tempi, mu = 320, alternative = "less")

Questo testa formalmente:

  • H₀: μ \(\geq\) 320;
  • H₁: μ < 320.
test_con_outlier

    One Sample t-test

t = 0.90745, df = 19, p-value = 0.8122
alternative hypothesis: true mean is less than 320
95 percent confidence interval:
     -Inf 395.5425
sample estimates:
mean of x 
      346

Il risultato “non significativo”

Con \(p\) = 0.8122, il ricercatore conclude:

“Il tempo di reazione medio non è significativamente minore di 320 ms.”

Ma è corretto?

L’outlier (890 ms) ha gonfiato la media e introdotto una distorsione nel risultato del test.

L’importanza di guardare i dati

# Senza l'outlier
tempi_puliti <- tempi[tempi < 500]

cat("Senza outlier:\n")
Senza outlier:
cat("  Media:", round(mean(tempi_puliti), 1), "ms\n")
  Media: 317.4 ms
cat("  n =", length(tempi_puliti), "\n")
  n = 19 
test_senza_outlier <- t.test(tempi_puliti, mu = 320, alternative = "less")

    One Sample t-test

     -Inf 319.3273
sample estimates:

 317.3684

Ora \(p\) = 0.0158 → risultato significativo.

Il problema delle correzioni “ad hoc”

L’approccio frequentista richiede:

  1. identificare gli outlier (ma con quale criterio?);
  2. decidere se rimuoverli (ma quando è giustificato?);
  3. applicare trasformazioni (log? radice quadrata?);
  4. usare test non parametrici (ma perdono potenza…).

Tutte queste sono decisioni arbitrarie che influenzano il risultato — si ricordino il problema dei gradi di libertà del ricercatore e la crisi della replicabilità discussi nelle Lezioni 15–16.

Parte 4: l’approccio bayesiano

Un modello più naturale

Invece di “correggere” i dati, possiamo usare un modello più flessibile.

L’idea: sostituire la distribuzione normale con la distribuzione \(t\) di Student, che ha code più pesanti.

\[ y_i \sim \text{Student-}t(\nu, \mu, \sigma), \] dove \(\nu\) (gradi di libertà) controlla quanto le code sono “pesanti”.

Perché la \(t\) di Student?

Il modello bayesiano robusto

Nella Lezione 24 abbiamo usato brms per la regressione sonno ~ stress_c. Qui il modello è più semplice — solo l’intercetta — ma cambiamo la famiglia della distribuzione:

# Creiamo il dataframe
dati_tempi <- data.frame(tempo = tempi)

# Modello con distribuzione t di Student
fit_robusto <- brm(
  tempo ~ 1,
  data = dati_tempi,
  family = student(),  # Distribuzione t invece della Normale
  seed = 42,
  backend = "cmdstanr",
  silent = 2,
  refresh = 0
)

Confrontiamo i due modelli

# Modello normale (standard)
fit_normale <- brm(
  tempo ~ 1,
  data = dati_tempi,
  family = gaussian(),
  seed = 42,
  backend = "cmdstanr",
  silent = 2,
  refresh = 0
)

Parte 5: la filosofia dietro i due approcci

L’approccio frequentista

Filosofia:

  • i parametri sono numeri fissi ma sconosciuti;
  • stimiamo usando i dati;
  • il valore-\(p\) misura quanto i dati sono “sorprendenti” sotto H₀.

Problemi:

  • richiede assunzioni rigide (normalità);
  • outlier = problema da “correggere”;
  • il risultato dipende da decisioni arbitrarie.

L’approccio bayesiano

Filosofia:

  • i parametri sono variabili casuali (Lezione 17);
  • esprimiamo incertezza con le distribuzioni;
  • possiamo scegliere modelli flessibili.

Vantaggi:

  • modelli robusti integrati naturalmente;
  • nessuna decisione arbitraria sugli outlier;
  • risposte dirette: “Qual è la probabilità che μ > 320?”

Le “correzioni” frequentiste

Problema Soluzione frequentista Problema della soluzione
Outlier Rimozione Quale criterio?
Non normalità Trasformazione Quale trasformazione?
Eteroschedasticità Test robusti Perdita di potenza
Dipendenza Correzioni Assunzioni aggiuntive

Ogni correzione introduce nuove assunzioni e decisioni arbitrarie.

L’approccio bayesiano: un framework unificato

Invece di “correggere”, modelliamo il fenomeno:

  • Outlier? → Usa distribuzione con code pesanti (t di Student).
  • Non normalità? → Usa la distribuzione appropriata.
  • Eteroschedasticità? → Modella la varianza.
  • Dipendenza? → Modelli gerarchici.

Tutto dentro un unico framework coerente — lo stesso framework brms che abbiamo usato nella Lezione 24 per la regressione.

Riepilogo

I punti chiave

  1. Il test \(t\) assume la normalità e può essere ingannato dagli outlier.

  2. L’approccio frequentista richiede correzioni ad hoc.

  3. L’approccio bayesiano permette modelli naturalmente robusti.

  4. La distribuzione \(t\) di Student è più tollerante ai valori estremi.

  5. Dobbiamo sempre guardare i dati prima di qualsiasi analisi.

Il messaggio fondamentale

“Non correggere i dati per adattarli al modello. Scegli un modello che si adatti ai dati.”

L’approccio bayesiano ci permette di costruire modelli più realistici, senza dover prendere decisioni arbitrarie su cosa fare con i dati “problematici”.
